# ui_dinos

## Summary
UI is all runtime uGUI + TMP built by CretaceaUiFactory: Screen Space Overlay, 1920x1080, match 0.5, with HUD/Journal/Menu canvases at sort order 10/25/40. The worst problems: (1) no TMP SDF assets exist for the six bundled fonts, so every string is LiberationSans with faux bold. (2) Every panel is a flat 2x2 white-sprite slab with no border, radius or shadow. (3) A cool teal/amber palette replaced the Godot original's warm theme. (4) Secondary text is 13-17 px, about 9-11 px at 720p. (5) The import script forces docs and maps to no mips, max 2048, BC1, and the doc modal shows them small. (6) There is no brightness setting. (7) The HUD art and the park logo are never used. Dinos: 4 unpacked prefabs (23.6k-49.5k tris, 1 mesh and 1 material each, no LOD) with identical HDRP Lit SSS materials. The SSS profile is registered correctly. The plastic look comes from blank AO maps, near-uniform smoothness, stray metallic values, one material for eyes/teeth/skin, no wetness and rig-stretch smearing. The T. rex skeleton uses the FBX material with no mask map. The visitors and park guide are imported but never placed (Godot spawned 16 people in the intro). The notes (187 lines) cite file:line for each claim.

## How to
- UI is 100% runtime C#: HudController/JournalController/MenuController build their canvases in Awake through CretaceaUiFactory.CreateRootCanvas (CretaceaUiFactory.cs:45-61: ScreenSpaceOverlay, ref 1920x1080, match 0.5; sort 10/25/40). build_all_scenes never touches UI layout; it only re-adds the 3 managers and wires interact_ring, damage_red and hud_minimap_route plus the menu scene names (CretaceaWorldAssembler.cs:945-981).
- Central restyle points in CretaceaUiFactory.cs: palette statics 19-31 (ButtonHover/ButtonPressed are dead), font resolvers 70-102, CreateText 177-210 (headers = Bold + characterSpacing 3.5, no outline/underlay), CreatePanel/CreateAnchoredPanel 126-175 using the 2x2 white sprite 389-397 (swap in a 9-sliced rounded sprite here), CreateButton 212-263, slider/toggle rows 265-378. Per-widget sizes and positions are literals in each Build* method (HudController.cs:313-511, MenuController.cs:350-653, JournalController.cs:188-410).
- Fonts need no code change: create TMP SDF assets at exactly Assets/Resources/UI/Fonts/'BarlowCondensed-Bold SDF', 'Barlow-Regular SDF' and 'CourierPrime-Regular SDF' (loaded at CretaceaUiFactory.cs:76/88/98), with LiberationSans SDF as fallback. Enter Play Mode Options disable domain reload (ProjectSettings/EditorSettings.asset:29-30), so the static font/sprite caches keep LiberationSans until a script recompile.
- Assets/Editor/CretaceaPbrImporter.cs:145-165 (OnPreprocessTexture) forces every texture on a /ui/, /hud/, /documents/, /docs/, /maps/, /icons/ or /fonts/ path to Sprite, mips off, max 2048 on every import. Inspector changes are reverted, so edit the postprocessor. Dino textures get 4096 + HQ compression through the /dinosaurs/ token (69-72, 167-215); /characters/ stays at 2048.
- Runtime Resources paths: Resources.Load<Sprite>('UI/Docs/{assetKey}') (MenuController.cs:229) and 'UI/Maps/hud_minimap_route' (JournalController.cs:264). The factory's 'UI/HUD/interact_ring|damage_red|vignette' loads (CretaceaUiFactory.cs:422, 446) point to a folder that does not exist, so procedural 128 px sprites are used unless the scene-serialized overrides are set.
- Dino materials and prefabs come from 'unity command cretacea build_dino_prefabs ... -- --overwrite true' (DinoAnimatorBuilder.cs:21-101). BuildOrUpdateHdrpMaterial (835-911) re-binds the textures and resets SmoothnessRemap 0.12/0.78, MaterialID 0, SubsurfaceMask 0.35 and the SSS_DinoSkin profile. Detail, thickness and subsurface-mask maps added to the .mat survive. BuildDinoPrefab (982-1076) rebuilds each prefab from the FBX, so hand edits to the prefabs (LODGroup, extra renderers) are lost.
- All 4 MAT_<Species>.mat files are identical HDRP/Lit SSS materials (keywords _MASKMAP _NORMALMAP SSS+TRANSMISSION, StencilRefGBuffer 14) using Assets/Settings/Rendering/SSS_DinoSkin.asset (hash 1075049788, registered in Assets/Settings/HDRPDefaultResources/DefaultSettingsVolumeProfile.asset:162-170). Tune skin globally in the profile and per-species in the .mat.
- Dinos exist only at runtime. StoryDirector.cs spawns them through DinoSpawner.Spawn: opening 545-561 (2 brachios at (-40,-6.2,-150) and (-95,-6.2,-185), 3 trikes near (-18,-6.2,-142), T. rex at (64,y,-28)); raptors at 790/827/933/985/1338/1352; valley T. rex at 1027. Prefabs are wired by CretaceaWorldAssembler.cs:984-1017; a missing prefab spawns a primitive fallback (DinoSpawner.cs:90-98). Check dino looks in Play mode at those beats.
- DinoConfig has no visual scale (only agent/eye heights and jaw angles). Species size is the FBX mesh at 1 m units and root scale 1: raptor 3.24 m long, T. rex 11.2 m, trike 7.6 m, brachio 19 m.
- MainWorld.unity is binary-serialized (6 MB), so GUID greps on it return nothing; check scene references in the editor. MainMenu.unity is text.
- Characters (Assets/Art/Characters/{park_guide,visitor_man,visitor_woman,visitor_teen,visitor_child}) have FBX rigs with embedded clips and MAT_* materials, but no prefabs, no animator controllers and no code references. The placement reference is ~/CretaceaBlackout/scripts/cutscene/opening.gd:39-58.
