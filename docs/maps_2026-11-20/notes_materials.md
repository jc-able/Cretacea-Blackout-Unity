# Materials / textures / shaders map (Cretacea: Blackout, Unity 6000.6.9f1 HDRP 17.6)

Read-only mapping. Paths relative to ~/CretaceaBlackoutUnity unless noted.

## 0. TL;DR for the look pass

1. UV stretch: every architectural surface is a scaled Unity cube (WorldArchitectureKit.cs:926-952) with UV0 + 1x1 tiling, so one 2048 texture covers a whole face: 14-19 texels/m on the 110x146 m / 131x64 m / 110x90 m slabs (Zone3:322, Zone1:797, Zone2:230). Biggest single texture-quality fix: world-space Planar/Triplanar (`_UVBase` 4/5 + `_TexWorldScale`) in `GetOrBuildPbr` (WorldMaterialPalette.cs:132-161).
2. Props: 40 prop FBXs use HDRP's auto FBX material (base+normal, metallic 0, constant smoothness from Blender shininess); their shipped `<prop>_MaskMap.png` (real metal/roughness) is never bound because no FBX has a material remap (all `externalObjects: {}`); only the 5 characters do.
3. Foliage: grass/fern/shrub cards are opaque, single-sided, no alpha clip, no translucency, no wind (FBX auto materials); their BaseColor alpha is 84-93 % transparent with near-black RGB underneath -> dark rectangles (inferred). Tropical trees/palms use 4096 RGB textures without alpha, capped to 2048.
4. Terrain: all 4 TerrainLayers bind `*_MaskMap_Wet` (constant gloss 0.68-0.90) because of a last-match-wins loop (Zone4_TerrainJungleAndDawnCoastBuilder.cs:233-243), in every preset; "Grass" layer albedo is straw (sRGB 0.59,0.52,0.35) and moss is orange -> desert read. Unused jungle sets exist (forest_floor, rock_mossy, bark_tropical).
5. Mask maps make the palette's metallic/smoothness args dead; "Wet" materials (ConcreteFloorWet, FloorTileWet, AsphaltWet) look exactly like dry ones; PlasterClean and DarkGranitePlinth have no textures at all.
6. Custom shaders are unlit and exposure-hacked: MAT_DawnOcean `_LuminanceScale 2600` (ocean + 29 stream boxes) is white at night EV; puddle overlay shader is unused; rain is self-lit grey. Nothing reads `_LightningFlashIntensity` or the trample globals; `_GlobalWetness` drives nothing visible, and StormRainOcclusionController overwrites the globals to 1.0/0.85 every frame.
7. Emissives are 10-14 nits with exposure weight 1: ~7.7 in the colour buffer at EV 0.6 (bloom threshold 1.15) = clipped blobs, ~0 by day; lamp FBX heads never glow (only glued emissive cubes do).

## 1. WorldMaterialPalette.cs: every palette material

Construction: ONE `new WorldMaterialPalette()` per build at Assets/Editor/WorldBuilder/CretaceaWorldAssembler.cs:193 (`BuildAllScenes`, CLI `cretacea build_all_scenes` :170-180), `AssetDatabase.SaveAssets()` at :208. Ctor -> `BuildAllCoreMaterials()` WorldMaterialPalette.cs:85-130. Output folder `Assets/Art/Materials/World` (:23).

Texture lookup `FindTextureSet` (WorldMaterialPalette.cs:526-550): scans every Texture2D under Assets/Art/Textures, substring-matches each hint against the WHOLE lower-case path, classifies by file name: `maskmap|mask_map` -> mask, `normal|_nor` -> normal, `albedo|basecolor|diff|color` -> base; first hit wins (FindAssets order, path-sorted in practice); stops at the first hint that yields a base. Height/BaseColor_Wet/MaskMap_Wet ignored (dry files sort first). Mask/normal found under an earlier hint are NOT reset if a later hint supplies the base (can mix sets; not observed in current .mats).

All PBR mats below: shader HDRP/Lit (guid 6e4ae406...), Opaque, single-sided, no alpha clip, `_UVBase=0` (UV0), tiling 1x1 (no code ever sets tiling/UV mode: grep `SetTextureScale|_UVBase|mainTextureScale` = 0 hits), `_NormalScale=1`, keywords `_MASKMAP _NORMALMAP _NORMALMAP_TANGENT_SPACE`, mask remaps forced to 0..1 (CretaceaPbrImporter.cs:499-506). OVERWRITE behaviour (important for hand edits):

- Emissive (:163-186), glass (:253-285), chainlink (:287-319), decals (:218-244), quad mats (:188-216) re-write all their listed props every build.
- NOT touched on rebuild (hand edits survive): `_UVBase`, `_TexWorldScale`, texture tiling/offset (m_Scale), `_BaseColor` of textured mats, detail maps, double-sided/alpha clip of PBR mats, `_HeightMap`, keywords set by HDRP validation. Hand edits to remaps / `_NormalScale` / `_Smoothness` / emissive values are REVERTED on every `build_all_scenes`.
- Nothing calls `HDMaterial.ValidateMaterial` (grep: 0 hits); keywords come from HDRP's MaterialPostProcessor on import. If code starts setting `_UVBase`/alpha clip/SSS, call `UnityEngine.Rendering.HighDefinition.HDMaterial.ValidateMaterial(mat)` (public, Library/PackageCache/com.unity.render-pipelines.high-definition@6fc877b69258/Runtime/Material/MaterialExtension.cs:369; also `SetAlphaClipping` :495, `SetDiffusionProfile` :513, `SetEmissiveColor` :443).

## 4. Prop FBX materials: import settings, remap, the mask-map gap

- All 149 FBX under Assets/Art: `materialImportMode: 2` (ImportViaMaterialDescription), `materialLocation: 1` (embedded in the FBX, read-only sub-assets), `materialSearch: 1` (RecursiveUp), `materialName: 0`; 144 have `externalObjects: {}` (no remap). - Who builds the material: HDRP's `FBXMaterialDescriptionPostprocessor` (Library/PackageCache/com.unity.render-pipelines.high-definition@6fc877b69258/Editor/AssetProcessors/FBXMaterialDescriptionPostprocessor.cs:25-154): HDRP/Lit; `DiffuseColor` tex -> `_BaseColorMap` (:85-94); `Bump`/`NormalMap` -> `_NormalMap` (:104-117); `Shininess` -> `_Smoothness = sqrt(shininess*0.01)` (:148-154); emissive (:119-146); FBX opacity -> Transparent alpha-BLEND with cutoff 0 (:44-79). - Result (live dump materials.txt:23-92): every prop `M_<prop>` has base+normal only, `mask=n`, `met=0.00`, constant smoothness from Blender roughness: e.g. switch_cabinet 0.84, generator_diesel 0.83, wet_floor_sign 0.80, fire_extinguisher 0.77, industrial_valve_wheel 0.66, lamp_post 0.64, crate 0.14, pallet 0.14 (materials.txt:35,82,75,89,56,42,37,92). `M_wrecked_kiosk_FasciaPlate` untextured (0.30,0.37,0.32) (:87).
- The gap: every prop ships `Textures/<prop>_MaskMap.png` (40 of 40 non-LOD prop FBXs, incl. Alternative: extend CretaceaPbrImporter with `OnPreprocessMaterialDescription` (order after HDRP's) to bind `<stem>_MaskMap.png` automatically.
