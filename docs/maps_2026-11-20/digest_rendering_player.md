# rendering_player

## Summary
I mapped runtime rendering and the player view without changing anything; the notes run to 155 lines. Main findings:
(1) The glove reads light grey because its albedo is about 0.006 (a texture averaging 0.04 linear times a 0.15 tint), so grey specular dominates. The likely source is a stale corridor reflection probe (Realtime, OnEnable, captured with the lights on), plus a 4.5 lm bounce fill. Outdoors the same glove reads black.
(2) The viewmodel custom pass (BeforePostProcess, depth clear) gets no fog, SSAO, contact shadows or motion vectors, and uses the world FOV: 78 vertical, about 110 horizontal.
(3) Rain occlusion depends on Camera.RenderWithShader, a Built-in-RP feature, so it rains indoors. On top of that, StormRainOcclusionController overwrites the rain and wetness globals every frame.
(4) Lightning comes from a directional light with no shadows, so it lights sealed interiors.
(5) The camera only sets TAA: dithering, stopNaNs and dynamic resolution are all off.
(6) Interior zones only affect audio.
AtmosphereController.cs was rewritten by the lead at 01:09 while I was working. Section 4a covers the new file and 4b the original port. All 7 profiles are tabulated in section 7.

## How to
- The player rig and cameras are generated by CretaceaWorldAssembler.BuildPlayerRigAndCameras (Assets/Editor/WorldBuilder/CretaceaWorldAssembler.cs:420-632): FOV 78, near 0.06, rig pivot (0.18,-0.14,0.34) :465, fill 4.5 lm :550, TAA only :600. 'cretacea build_all_scenes' re-applies all of it, so change values there or in the prefab and scripts, never in the scene. MainWorld.unity is a BINARY scene and cannot be grepped or diffed.
- Flashlight values exist in 3 places, and FlashlightController.ConfigureHdrpLights (Assets/Scripts/Player/FlashlightController.cs:138-174, defaults :30-36) wins in Awake. The prefab's spot reflector is ON (PF_FlashlightFpsRig.prefab:482), so changing the cone angle changes candela with lumens held constant. Flicker drives SetLightDimmer, so set base brightness with intensity, not the dimmer.
- Viewmodel: the Main Camera culling mask excludes layers 12 and 13. PF_ViewmodelCustomPassVolume (BeforePostProcess, priority 100) clears depth, then draws Forward/ForwardOnly/SRPDefaultUnlit with forced LessEqual depth (Assets/Scripts/Rendering/ViewmodelCustomPass.cs:59-101). Keep Lit Shader Mode = Both in HDRP High Fidelity.asset:258, or the arm disappears. ViewmodelCameraConfig is [ExecuteAlways] and strips layer 12 from its camera.
- FOV: CameraDirector.UpdateFpsFov (Assets/Scripts/Player/CameraDirector.cs:113-131) rewrites CM_FPSCamera.Lens every frame from SaveManager.Settings.fieldOfView (VERTICAL, clamped 60-100, default 78 at SaveManager.cs:27), plus +6.5 sprint and -2.5 crouch. Any FOV set on the Main Camera or the CM lens is overwritten.
- Atmosphere: the lead's AtmosphereController loads Resources/Atmosphere/Look_<Preset> into 5 weighted Volumes and disables [GlobalAtmosphereVolume] only if all 5 load (AtmosphereController.cs:238-267). SetPreset callers: StoryDirector.cs:297 (0 s), 440 (0), 508 (4.0), 518 (4.5), 732 (8.0), 1464 (8.5), plus the jump tool at CretaceaWorldAssembler.cs:1670.
- Every build regenerates MainWorld_RuntimeAtmosphere.asset and MainMenu_StormAtmosphere.asset from Preset_BlackoutStorm.asset and rewrites Preset_DawnCoast.asset (CretaceaWorldAssembler.cs:2086-2246). The edit-mode chapter jump swaps the global Volume's sharedProfile to Preset_*.asset (:1729-1742); that is a scene edit, so do not save the scene after a jump.
- StormRainOcclusionController (Assets/Scripts/Rendering/StormRainOcclusionController.cs:79-96, 179-185) rewrites _RainIntensity, _GlobalWetness and _CretaceaRainOcclusionTex every Update from its own fields (1.0 / 0.85). Drive its RainIntensity/GlobalWetness properties, or remove that per-frame write, before relying on per-preset wetness. StoryDirector never touches it.
- All room reflection probes and InteriorZone triggers come from WorldArchitectureKit.BuildRoomReflectionProbe (Assets/Editor/WorldBuilder/WorldArchitectureKit.cs:747-790): Realtime, OnEnable, multiplier 0.45. That is the one place to change probe mode for every room. InteriorZoneVolume raises GameEvents.OnInteriorChanged(isIndoors, zoneId), which only audio uses today; it could drive interior Volumes or stop rain indoors.
- Fades, the 92 px letterbox, the red damage vignette and title cards are uGUI Images in HudController (Assets/Scripts/UI/HudController.cs:698-755), driven by GameEvents.RaiseScreenFade / RaiseLetterbox / RaiseDamageFlash. Only AtmosphereController touches Volumes. Camera shake (GameEvents.RaiseCameraTrauma -> CameraDirector.AddTrauma) moves only ShakeHost, the FPS camera's parent.
- LightGroupMember (Assets/Scripts/Core/LightGroupMember.cs:120-172) scales lights with SetLightDimmer and emissives with an MPB _EmissiveColor x factor. It caches base values from the sharedMaterial at enable, so changes to emissive or light intensity need a Play restart. Room probes are not re-rendered when power changes.
- Fixed-luminance shaders multiply by GetCurrentExposureMultiplier(): rain (Assets/Shaders/CretaceaRainParticle.shader:117, brightness 1.35) and CCTV (Assets/Shaders/CretaceaCctvScreen.shader:139, 8 nits live). Retune them every time the exposure model changes.
