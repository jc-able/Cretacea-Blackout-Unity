# assembler_kit

## Summary
build_all_scenes (A:189) rebuilds both scenes from scratch with NewScene(Single) and no save prompt. MainMenu goes first (A:196), then MainWorld (A:199): zones 1-4, flashlight pickup, player rig, viewmodel pass, rain, [Managers] (one global Volume at priority 10, key light, 55 lux lightning with no shadows, 5 serialized presets), reverb zones, NavMesh bake, save. Every run deletes and re-copies MainWorld_RuntimeAtmosphere and MainMenu_StormAtmosphere from Preset_BlackoutStorm, and rewrites fields in Preset_DawnCoast. Hand edits to the scenes and those assets are lost; prefabs and the other four presets survive. Root causes in the kit: (1) BuildHdrpLight never sets lightUnit, so values written as lumens land as candela (98 of 104 lights). (2) CreateBox uses raw cube UVs and every palette material tiles 1x1, so each wall or floor shows one stretched texture. Also missing: lightmaps, APV, LODs, occlusion bake and local Volumes, and only 4 places set static flags. The 62 DefaultHDMaterial renderers are hidden layer-13 RainBlocker slabs, but realtime probes (captured once on enable) still render them. Look-pass hooks: A:359 for MainWorld, before A:1563 for MainMenu.

## How to
- Run with `unity command cretacea build_all_scenes` (arg bake_navmesh, default true) or the menu Cretacea/World/Build All Scenes. Both call BuildAllScenes (Assets/Editor/WorldBuilder/CretaceaWorldAssembler.cs:189-237): MainMenu is built first (A:196), MainWorld second (A:199), then EditorBuildSettings is overwritten (A:202-206). It needs Edit mode. NewScene(Single) at A:270 and A:1285 throws away the open scene with no prompt, so save any work first.
- Hook a look pass at A:359 (after the door/document count, before MarkSceneDirty/SaveScene) for MainWorld, and before A:1563 for MainMenu. Anything that changes colliders must run before the NavMesh bake at A:351-352. ApplyEditModeLightGroupState (A:348, A:1802-1832) only flips Light.enabled per LightGroupId.
- Fix lights once, in WorldArchitectureKit.BuildHdrpLight(parent, name, worldPos, euler, LightType, Color, float intensityLumens, float range, LightGroupId, volumetricDimmer=1, castShadows=false, spotOuterAngle=60, colorTempK=5500, sequenceOrder=0, rotatingBeacon=false, pulsingEmergency=false, blackoutBackupFactor=0, Renderer[] pairedEmissives=null) (Assets/Editor/WorldBuilder/WorldArchitectureKit.cs:657-704). That covers 92 MainWorld and 7 MainMenu lights. At runtime LightGroupMember caches the serialized intensity and multiplies it by a power factor (Assets/Scripts/Core/LightGroupMember.cs:90-96,146), so the serialized value and unit are what count.
- All kit geometry comes from CreateBox(parent, name, localPos, size, mat, addCollider=true, euler=null) (K:926-952): a scaled Unity cube on layer Environment, 0..1 UVs per face, no static flags, shadows on. BuildWallWithOpenings (K:94-175) splits a wall into Pier/Lintel/Sill/Frame boxes in a local frame where +Z runs along the wall. Only wall segments (K:222-225), room floors and ceilings (K:468, K:473) and window glass (K:273) get static flags.
- Regenerated every build, so hand edits are lost: both scenes (binary-serialized, cannot be grepped); MainWorld_RuntimeAtmosphere.asset and MainMenu_StormAtmosphere.asset (DeleteAsset + CopyAsset from Preset_BlackoutStorm, new GUIDs, A:2086-2203); the sky/exposure/fog fields of Preset_DawnCoast (A:2205-2246); palette material values (Assets/Editor/WorldBuilder/WorldMaterialPalette.cs:132-186); AtmosphereController.presets (A:802-919). Edits survive in: the prefabs (PF_FlashlightFpsRig, PF_StormRainSystem, PF_ViewmodelCustomPassVolume, PF_TrexSkeleton, the dinos) and Preset_OpeningDusk/BlackoutStorm/InteriorEmergency/PowerRestored. BlackoutStorm is copied into both runtime profiles.
- Per-chapter exposure, fog and key light come from the 5 AtmosphereProfile entries at A:807-896. AtmosphereController writes Fixed exposure at Assets/Scripts/Core/AtmosphereController.cs:411-412. A second default table sits in AtmosphereController.cs:163-252 and is used when presets has fewer than 5 entries. The live GoldenDay fog (180 m) matches that table, not the assembler's 220 m, so check the live presets and change both tables. The only Volume is [GlobalAtmosphereVolume] (A:719-741).
- jump_chapter in Play mode only calls StoryDirector.StartFromCheckpoint(checkpoint, freshPreset:true), then teleports for Corridor, ServicePaths, Escape and DawnCoast (A:1631-1693). The table's VolumeProfilePath, Blackout and Aux values apply only in Edit mode, which also swaps the global Volume's profile for a Preset_*.asset (A:1729-1742). Never save after an edit-mode jump, and judge the look in Play mode.
- The 62 DefaultHDMaterial renderers are layer-13 RainBlocker proxies (K:792-807): 45 above the lobby skylight, 14 room roofs, 3 placed directly. MainMenu adds 17 more. Main Camera and the CCTV cameras exclude layers 12 and 13 (A:597; Assets/Editor/WorldBuilder/Zone1_VisitorCenterBuilder.cs:243). Reflection probes (default cullingMask -1) and any custom capture camera do render them; aerial_vc_close.jpg shows the lobby roof as a grey slab. Mask layers 12 and 13 in capture cameras instead of changing the blocker material.
- Reflection probes come from BuildRoomReflectionProbe (K:746-790): Realtime with OnEnable capture, multiplier 0.45, clear to colour, no culling mask. There are 11 in MainWorld (9 in Zone1, 2 in Zone3) and none outdoors. Its InteriorZoneVolume is a trigger collider, not an HDRP Volume, so interiors have no local exposure or fog override.

## Top issues

- [high] **Kit lights authored in lumens are applied as candela (12.6x or more too bright)** — Assets/Editor/WorldBuilder/WorldArchitectureKit.cs:684 (BuildHdrpLight never sets light.lightUnit); also Assets/Editor/WorldBuilder/Zone3_SubstationAndYardBuilder.cs:242-247; 98/104 lights read Candela in dump/lights.txt
  FIX: Set light.lightUnit = LightUnit.Lumen before light.intensity (and pick light.enableSpotReflector explicitly for spots), then rebalance by target illuminance. At fixed EV 0.6-1.2, mid-grey needs only ~2-5 lux. Day-scale lights (Lobby_SkylightDayFill 85,000, Lobby_MainN/S 58,000, Talon floods 28,000) need a per-preset intensity multiplier on LightGroupMember or AtmosphereController, or a group that is off at night.
- [high] **Every kit surface shows one stretched texture (cube UVs, palette tiling 1x1)** — Assets/Editor/WorldBuilder/WorldArchitectureKit.cs:926-952 (CreateBox) + all MAT_* palette materials tile=(1,1) uv=0 (dump/materials.txt)
  FIX: For static architecture materials, switch to HDRP Lit triplanar world mapping (_UVBase=5, _ObjectSpaceUVMapping=0, _TexWorldScale ~ 1/tile metres, then HDMaterial.ValidateMaterial); keep moving doors on UV0. Or make CreateBox emit a generated box mesh with metric UVs (face size / tile metres), cached by size and saved as assets.
- [high] **No bounce light and no interior volumes: unlit areas go black** — Assets/Editor/WorldBuilder/CretaceaWorldAssembler.cs:719-723 (only Volume); ContributeGI flags inert at WorldArchitectureKit.cs:222-225/468/473; lightmapCount=0, no APV/probes (dump/env.txt)
